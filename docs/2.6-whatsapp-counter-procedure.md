# 2.6 WhatsApp counter procedure

Use this until transactional email exists. **Do not** tell the customer they will get an email.

**Number:** +60 17-405 6993 (same as the site).

## When a paid pickup order appears in admin

1. Open **Orders** / fulfillment. Confirm payment is **captured** (webhook), not merely “browser returned.”
2. WhatsApp the customer on the number they entered at checkout. If that field is empty, use the email only as a last resort — still do not promise email.
3. Send:

> Ekoway Hardware — we have your paid order #[ORDER_ID].  
> Please collect at No. 43-44, Lorong Salim 17, Jalan Salim, 96000 Sibu.  
> Bring this message or the order number.  
> Call 084-253 883 or reply here if you need to change the time. Please WhatsApp or call before you travel.

4. Mark fulfillment **received → picking** when you start the pick, then **ready_for_pickup** when the bag is at the counter.
5. On collection, mark **completed**. Do not invent a return window or warranty in the chat.

## If payment failed or is still pending

Do not pick stock. Reply only if they message you:

> We have not received a confirmed payment for that order yet. If you were charged, send the HitPay reference and we will check.

## If they ask for delivery

Launch is pickup-only. Quote by WhatsApp; do not enable the website delivery option.

## If they ask for a return / refund

Do not quote a fixed number of days. Take the request, check the item, then follow the owner’s instruction. Refunds, when agreed, go through the payment provider so stock can restock.
